# Bazyli Kok — Portfolio

A minimal, static portfolio for [bazylikok.github.io](https://bazylikok.github.io/).

## Structure

- `/` — recruiter-focused overview and selected work
- `/thesis/` — bachelor thesis case study

The site uses semantic HTML and custom CSS, with no framework, build step, analytics, or client-side JavaScript.

## Local preview

Run any static file server from the repository root, for example:

```powershell
python -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.
